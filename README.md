Overview
This HR Analytics Dashboard was developed using Tableau to analyze employee attrition and workforce trends. The dashboard provides valuable insights into employee demographics, job satisfaction, department-wise attrition, and workforce distribution to support data-driven HR decisions.

Key Metrics
Total Employees
Employee Attrition
Attrition Rate (%)
Active Employees
Average Employee Age
Dashboard Features
Attrition Analysis by Gender
Department-wise Attrition Analysis
Employee Age Group Distribution
Job Satisfaction Ratings
Education Field-wise Attrition
Gender and Age Group Comparison

Tools Used
Tableau
Excel/CSV Dataset

Key Insights
Identified departments with the highest attrition.
Analyzed attrition trends across different age groups and genders.
Evaluated employee job satisfaction levels.
Explored workforce demographics and education backgrounds.
Business Value

This dashboard helps HR teams monitor employee turnover, understand workforce patterns, and make informed decisions to improve employee retention and organizational performance.
